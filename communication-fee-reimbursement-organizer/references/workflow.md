# 通讯费报销整理工作流

## 1. 文件盘点

先把用户提供的文件分成这些角色：

- 制度或政策：通常在制度汇编、员工福利明细、电话费报销制度中。
- 报销模板：用户常称为“通讯费第1季度文件”或“通讯费模板”；如果用户没有另传新版模板，使用内置模板 `assets/templates/通讯费第1季度.docx`。
- 人力资源名单：通常是 `.xlsx`，包含姓名、工作部门、岗位、级别、人员类别等字段。
- 电话费/燃油费报销人员台账：通常是 `.xlsx`，用于核对任命人员、无任命人员、历史话费福利、审批依据和报销开始月份。
- 通讯录：至少两个来源，例如公司通讯录和煤矿通讯录，通常是 PDF。
- 发票或发票金额：可能是 PDF、图片、Excel、截图或用户文本。

如果缺少发票或金额数据，可以先做模板和核对口径，但不能生成完整报销金额。

本 skill 内置了 2026年4月公司通讯录和煤矿通讯录，见 `references/address-books-2026-04.md`。如果用户提供更新版通讯录，必须优先使用更新版，并把内置通讯录仅作为历史对照。

本 skill 也内置了 2026 年电话费/燃油费报销人员统计表和 2026-06-11 人力资源在职人员表，见 `references/bundled-workbooks.md`。如果用户提供更新版人员或福利台账，必须优先使用更新版，并把内置工作簿仅作为历史对照。

## 2. 模板保护

复制模板到输出目录后再填报。不要直接修改内置模板资产。模板是最终格式标准，必须完全按照模板进行填写，不能擅自改动字体、字号、行高、列宽、边框、对齐、合并单元格、页边距、页眉页脚、签字栏、公式或整体版式。

填报时只能改需要填写的数据单元格。除非用户明确要求改格式，否则不能为了“看起来更好”而调整样式；不能重建表格，不能用程序默认样式替换模板样式。

读取并记录：

- 表头名称和列顺序。
- 每人占几行、每个月如何呈现。
- 合计行位置、公式、签字行。
- 合并单元格、字体、字号、加粗/斜体、对齐方式、边框、底纹、行高、列宽、页边距、页眉页脚。

常见列包括：通讯费、序号、姓名、级别、电话号码、报销标准（元/月）、报销月份、发票金额（元）、实报金额（元）、合计金额（元）。实际列名以模板为准。

`级别` 列按显示优先级填写：如果人员姓名后面或人员记录中有明确级别，填相应级别；如果没有明确级别，填 `2026年：电话费、燃油费报销人员统计.xlsx` 或用户提供的新版电话费/燃油费报销人员台账中的岗位名称，例如 `办事员`、`资料员`、`主管`、`专员`、`董事长`、`总经理` 等。专员类人员写岗位名称，不写笼统的审批类别。若人员因年度劳模、优秀班组长等荣誉或专项资格享受通讯费，必须按来源体现年份和称号，例如 `2025年优秀班组长`。不要把 `请示审批报销`、`请示审批`、`审批报销`、`历史福利`、`无任命人员话费福利` 等审批依据、来源表名称或报销原因写进 `级别` 列；这些内容只放在核对依据、备注、异常清单或审计证据里。

需要新增人员时，复制模板已有人员的数据行样式和合并单元格结构，不要重建表格；新增行必须继承模板的字体、字号、边框、行高、列宽、公式和对齐方式。

内置模板路径：`assets/templates/通讯费第1季度.docx`。使用前先复制到任务输出目录，再在副本上填报。

## 3. 政策提取

从制度源中提取：

- 各级别或岗位每月通讯费标准。
- “低于限额实报实销，超限按最高限额报销”等报销原则。
- 岗位变动后从哪个月执行新标准。
- 新任命、转正、缺勤等影响报销资格的规则。
- 特殊岗位，例如司机、采购业务人员、对外联络性质人员。

如果政策和用户给出的口径冲突，优先使用用户本次明确指定的口径，并在最终说明中写清楚。

## 4. 人员与通讯录核对

从 HR 名单建立人员表，至少保留：

- 姓名
- 工作单位/部门
- 岗位
- 级别
- 人员类别或在职状态

如果没有新版 HR 名单或报销人员台账，直接使用内置 `assets/data/1.人力资源报表- 20260611-力量煤业_副本.xlsx` 和 `assets/data/2026年：电话费、燃油费报销人员统计.xlsx` 建立人员/福利资格核对表。

填模板时，`级别` 列按以下顺序确定显示值：

1. 人员姓名后面、人员台账或 HR 记录中有明确个人级别时，填写该级别。
2. 因年度劳模、优秀班组长等荣誉或专项资格享受报销时，填写带年份的荣誉/资格称号，例如 `2025年优秀班组长`。
3. 没有明确级别或荣誉称号时，填写电话费/燃油费报销人员台账的 `岗位` 或 `岗位名称`；专员类人员也按岗位名称填写。
4. 台账岗位缺失时，再退回 HR `岗位` 字段，并把“台账岗位缺失，采用 HR 岗位”写入异常清单。

匹配人员时先用姓名+身份证号或手机号，必要时结合工作部门消歧。审批依据只用于证明资格或开始月份，不能替代级别、荣誉称号或岗位名称。

报销明细表的人员顺序必须按人员级别从高到低排序，再生成 `序号` 和最终表格行。排序用的 `排序级别` 可以来自 HR `级别`、任命级别、政策标准、荣誉/专项资格或岗位可明确映射出的级别，但只用于排序；不能覆盖上面的 `级别` 列显示值。排序层级见 `references/policy-cheatsheet.md` 的“明细表排序级别（从高到低）”。同级人员保持来源表或核对明细中的原始顺序，除非用户本次指定其他同级排序规则。

如果无法判断某人的排序级别，不要自行抬高或降低等级；把该人员放在明细表末尾的“无法确认级别”组，并在异常清单中列明姓名、来源字段、缺失或冲突原因。

从两个通讯录提取姓名、部门、职务和手机号。手机号统一规范为 11 位数字；有空格、短横线、全角字符时先规范化。

如果没有新通讯录，直接加载内置 `references/address-books-2026-04.md` 建立联系人表，不需要重新解析原始 PDF。

匹配优先级：

1. 发票手机号与通讯录手机号完全一致。
2. 通讯录手机号与 HR 姓名、部门同时匹配。
3. 只有姓名匹配时，必须检查重名；不能直接当作确定结果。

当发票号码和通讯录号码不一致时，模板中的电话号码按通讯录填写，同时在异常清单中说明发票号码、通讯录号码、人员姓名和来源。

## 5. 发票核对

每张发票至少核对并记录：

- 发票号码或可追踪编号
- 开票日期
- 购买方名称
- 购买方税号
- 地址、电话
- 开户银行
- 银行账户
- 发票金额
- 对应手机号或账户号
- 服务月份或账期

比较开票信息时先规范化空格。例如税号 `9115 0600 7971 5483 15` 和 `911506007971548315` 视为同一税号。银行账号也按去空格后比较。

不一致项目必须进入异常清单，不能只在最终摘要中笼统说明。

## 6. 按人按月拆分和金额核算

以“每人每月”为最小单位生成明细：

- 发票明确账期时，按账期月份填报。
- 模板是季度报销且发票未明确月份时，按该季度月份处理，但要在异常清单中标注“账期需确认”。
- 同一人多张发票覆盖同一月份时，先合并该人该月发票金额，再套用月标准。
- 多人共用一张发票或一个总金额时，必须有可追溯拆分依据；没有依据时不要自行平均分摊。
- `发票金额` 填该人员该月份的原始发票/账单金额，不因报销标准而改小。
- `实报金额` 必须由本次核算重新计算，不能照抄 `发票金额` 或沿用模板旧数。
- 当 `发票金额` 大于 `报销标准` 时，超过标准的部分不予报销；模板中的 `实报金额` 只能填标准金额。

计算口径：

```text
发票金额 = 该人该月可追溯发票/账单金额合计
实报金额 = min(该人该月发票金额, 该人该月报销标准)
超额不予报销金额 = max(该人该月发票金额 - 该人该月报销标准, 0)
合计金额 = 该人在本报销周期内各月实报金额合计
```

金额显示保留两位小数。模板已有公式时优先让公式计算；填完后复核公式结果。

金额核对示例：若某人月标准为 200.00 元，4 月发票金额为 208.00 元，则 `发票金额` 填 208.00，`实报金额` 填 200.00，8.00 元记为超额不予报销。

## 7. 按部门整合发票 PDF

在报销明细表生成并复核后，如果用户提供了发票 PDF、图片或扫描件，继续按部门整合发票 PDF。

排序权威来源是已经按人员级别从高到低排好的最终报销明细表，而不是文件名、发票号、开票日期或文件创建时间。处理顺序：

1. 从已填好的报销明细表读取每一条明细的部门、序号、姓名、报销月份、手机号、发票金额和实报金额。
2. 以部门为分组，同一部门内部按报销明细表中的人员出现顺序排列；同一人多个月份或多张发票时，按明细表中的月份/行顺序排列。
3. 将每张发票文件匹配到明细行。优先用手机号、发票号、账期月份、姓名和金额交叉匹配；不能只靠文件名猜测。
4. 每个部门输出一个合并 PDF，例如 `财务部-通讯费发票汇总.pdf`、`综掘队-通讯费发票汇总.pdf`。合并时保留原发票页面内容，不裁剪、不缩放、不重排发票内部内容。
5. 如果发票是图片，先转换为 PDF 页面再合并；转换后仍按明细表顺序插入。
6. 对每个部门生成排序清单，记录 PDF 页码范围、人员、月份、发票号/文件名和金额，便于人工复核。

不能匹配到明细行的发票、同一发票可能对应多个人、缺发票、重复发票、部门不一致或金额不一致，都必须进入异常清单。没有明确对应关系时不要强行合并到部门 PDF。

## 8. 异常清单

异常清单至少包含这些列：

- 类型：手机号不一致、通讯录缺失、HR缺失、重名、开票信息不符、金额超标准、账期缺失、拆分依据缺失、发票文件缺失、发票重复、发票无法匹配明细、部门 PDF 顺序需确认等。
- 人员/手机号/发票号。
- 来源文件和位置。
- 发现的问题。
- 本次处理方式。
- 需要人工确认的内容。

异常清单的语气要明确可执行，例如“模板电话按通讯录填 138...；发票号码为 139...，需确认是否为本人新号码”。

## 9. 交付前检查

完成后做这些检查：

- 模板格式、页边距、签字行、表格边框没有明显变化。
- 字体、字号、加粗/斜体、对齐方式、边框、底纹、合并单元格、行高、列宽、公式、页眉页脚与模板保持一致；除填写数据外没有擅自改动格式。
- 每人每月都有对应标准、发票金额、实报金额。
- `级别` 列逐人按显示优先级填写：有明确级别则写级别，有年度劳模/优秀班组长等资格则写带年份称号，没有级别则写岗位名称；专员类写岗位名称；没有出现 `请示审批报销`、审批依据、来源表名称或报销原因。
- `序号` 和人员顺序已按人员级别从高到低排列；同级人员保持来源顺序；无法确认排序级别的人员已放在末尾并进入异常清单。
- 总计等于所有实报金额合计。
- 超标准月份已按标准封顶。
- 逐行核对 `实报金额 = min(发票金额, 报销标准)`；如果发票金额超标准，确认超额部分没有进入实报金额和合计金额。
- 分别汇总发票金额、实报金额、超额不予报销金额；最终摘要中说明三项金额。
- 开票信息核对结果已覆盖每张发票。
- 如果输出部门发票汇总 PDF，逐部门核对 PDF 页序与报销明细表顺序一致；每个发票文件都能追溯到明细表中的部门、人员、月份和金额。
- 异常清单没有遗漏需要解释的电话号或人员差异。
