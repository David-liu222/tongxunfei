# 力量煤业通讯费报销口径速查

此文件记录从用户提供的力量煤业制度/员工福利明细中整理出的常用口径。若用户本次提供更新版本制度，以更新版本为准。

## 月度标准

| 级别或岗位 | 通讯费标准 |
| --- | ---: |
| 总经理级（含）以上 | 800 元/月 |
| 副总经理级、高级经理级（含）以上 | 600 元/月 |
| 正经理级 | 400 元/月 |
| 副经理级 | 300 元/月 |
| 主管级 | 200 元/月 |
| 司机、采购业务人员 | 200 元/月 |
| 其他经批准的对外联络性质员工 | 最高 200 元/月 |

## 级别列显示口径

报销明细表 `级别` 列按以下优先级填写：

1. 人员姓名后面、人员台账或 HR 记录中有明确个人级别时，填写该级别。
2. 因年度劳模、优秀班组长等荣誉或专项资格享受通讯费时，填写带年份的荣誉/资格称号，例如 `2025年优秀班组长`。
3. 没有明确级别或荣誉称号时，填写电话费/燃油费报销人员台账中的岗位名称。
4. 专员类人员写岗位名称，不写笼统的审批类别。

`请示审批报销`、`请示审批`、`历史福利`、`无任命人员话费福利` 等审批依据只作为资格证据，不能写入 `级别` 列。

## 明细表排序级别（从高到低）

报销明细表必须先按下列顺序排列人员，再生成 `序号`。此顺序只作为排序键，不替代上面的 `级别` 列显示口径。

| 排序值 | 排序级别 | 常见匹配文本 |
| ---: | --- | --- |
| 1 | 总经理级（含）以上 | 董事长、总经理、总经理级 |
| 2 | 副总经理级、高级经理级（含）以上 | 副总经理、副总级、高级经理 |
| 3 | 正经理级 | 正经理、经理、部门经理 |
| 4 | 副经理级 | 副经理、副科级 |
| 5 | 主管级 | 主管 |
| 6 | 经批准对外联络、业务岗位或专项资格 | 司机、采购业务人员、经批准员工、办事员、资料员、专员、年度劳模、优秀班组长 |
| 99 | 无法确认级别 | 缺失、冲突或不能映射到上述级别 |

同一排序级别内保持来源表或核对明细的原始顺序，除非用户本次明确指定同级排序规则。无法确认级别的人员放在末尾，并写入异常清单。

## 常用原则

- 通讯费低于限额时实报实销，超过限额时按最高限额报销。
- 员工岗位变动后，次月执行新岗位标准。
- 主管级或副科级（含）以上员工自任命次月起可按标准报销。
- 其他员工通常需转正后申请，经批准后按标准执行。
- 因员工自身原因当月无出勤的，取消当月通讯补助。
