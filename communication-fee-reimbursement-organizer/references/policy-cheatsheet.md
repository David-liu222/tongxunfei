# 力量煤业通讯费报销口径速查

此文件记录从用户提供的力量煤业制度/员工福利明细中整理出的常用口径。若用户本次提供更新版本制度，以更新版本为准。

## 月度标准

| 级别或岗位 | 通讯费标准 |
| --- | ---: |
| 总经理级（含）以上 | 800 元/月 |
| 副总经理级、高级经理级（含）以上 | 600 元/月 |
| 正经理级 | 400 元/月 |
| 副经理级 | 300 元/月 |
| 主管级 | 200 元/月 |
| 司机、采购业务人员 | 200 元/月 |
| 其他经批准的对外联络性质员工 | 最高 200 元/月 |

## 常用原则

- 通讯费低于限额时实报实销，超过限额时按最高限额报销。
- 员工岗位变动后，次月执行新岗位标准。
- 主管级或副科级（含）以上员工自任命次月起可按标准报销。
- 其他员工通常需转正后申请，经批准后按标准执行。
- 因员工自身原因当月无出勤的，取消当月通讯补助。
